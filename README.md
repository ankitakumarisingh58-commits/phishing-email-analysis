Phishing Email Analysis
Project Overview

This project focuses on identifying phishing emails, analysing suspicious messages, and understanding safe email reporting procedures.

Objectives
Analyse five sample phishing and genuine emails.
Identify common phishing warning signs.
Prepare a checklist for detecting suspicious emails.
Explain a safe process for reporting phishing emails.
Create a one-page staff awareness guide.
Project Contents
Phishing_Email_Analysis_Project.pdf — project report containing sample email analyses, a warning-sign checklist, reporting steps, and an awareness guide.
Key Learning
Recognising suspicious email senders and links.
Identifying urgency and requests for sensitive information.
Verifying emails through official channels.
Reporting suspicious messages safely.
Tools Used
GitHub
PDF documentation
Cybersecurity awareness and email analysis
Conclusion

This project helps users understand common phishing techniques and learn how to identify and report suspicious emails.
